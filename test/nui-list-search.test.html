nui-list — setSearch(term)

Search state used to be set-only-by-user, so a caller could not point an existing list at a record — a notification saying "report.pdf is ready" could navigate to the scope and no further. setSearch() is synchronous by contract, updates the visible control, announces once, and throws when the list was never configured for search (issue #63).
