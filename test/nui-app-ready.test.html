nui-app — ready without an animation frame

The shell is gated by nui-app:not(.nui-ready) { display: none }, and readiness used to ride on requestAnimationFrame. An embedded pane the host never composites delivers no frames while document.hidden stays false — so the whole shell stayed invisible, with no console error (issue #77). This page stubs requestAnimationFrame out before the library loads and asserts the shell still comes up. Open through the dev server: http://127.0.0.1:5500/test/nui-app-ready.test.html
