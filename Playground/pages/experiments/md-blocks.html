MD-Blocks

An experimental probe: rendering an MD-Blocks document through nui-markdown.

What this is

MD-Blocks is an enhanced Markdown authoring format — a spec, not a tool. Structure (sections, blocks, columns, named data) rides in invisible HTML comments and YAML frontmatter, while the content stays pure CommonMark. Each root-level --- starts a new section, which doubles as the unit for a slideshow renderer.

The spec lives at github.com/herrbasan/md-blocks. This library is the intended consumer: a nui-blocks renderer component that nui-markdown grows into.

Current state. Directive support is now active in nui-markdown. The document renders as structured MD-Blocks: sections separated by ---, mb:block containers, mb:columns/mb:col grids, media blocks with figure/figcaption, repeating chrome slots, and mb:var data cards. YAML frontmatter renders as a collapsed metadata disclosure by default.
