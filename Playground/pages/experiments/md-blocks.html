MD-Blocks

An experimental probe: rendering an MD-Blocks document through nui-markdown.

What this is

MD-Blocks is an enhanced Markdown authoring format — a spec, not a tool. Structure (sections, blocks, columns, named data) rides in invisible HTML comments and YAML frontmatter, while the content stays pure CommonMark. Each root-level --- starts a new section, which doubles as the unit for a slideshow renderer.

The spec lives at github.com/herrbasan/md-blocks. This library is the intended consumer: a nui-blocks renderer component that nui-markdown grows into.

Current state. Directive support has not landed yet — a structure-aware renderer is still to come. For now the document renders as ordinary Markdown: HTML comments are removed (as in every renderer, so the mb: directives are simply gone), and each section separator renders as a horizontal rule. Two pieces are already live and were the reason to build this page: the YAML frontmatter renders as a collapsed metadata disclosure by default, and images are now sized to their container instead of overflowing it.
