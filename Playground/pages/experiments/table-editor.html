Table Editor

A native <table> that becomes editable in place. The table is the model — no shadow copy, no wrapper in the saved output.

Status: complete — feel-check signed off. Replaces the dropped attempt at #page=experiments/dropped-table-editor.

Click a cell to type. Tab and Shift+Tab walk, Enter moves down a column, the arrow keys move between cells, and pasting TSV from a spreadsheet grows and fills the grid. Alignment, the header toggle and inserting a row or column all live in the toolbar above the table — insert puts the new row or column at your selection, and Ctrl-click inserts before it instead of after.

The one gesture worth describing: select a whole row or column and it gains a drag grip and a delete ×, at opposite ends of the band. Click a cell, then Shift+click the last cell of its row — or of its column, down to the bottom. Drag the grip to reorder; the × removes the whole band. Everything else is self-explanatory.

Serialization to a GitHub Flavored Markdown pipe table, regenerated on every change. Alignment becomes the delimiter row, so a right-aligned number column survives a round trip.

No Header Row

GFM has exactly one header row, so a table can be headerless. The toggle in the top zone converts the first body row into <thead> and back, without losing data.

Enhancing a Table In Place

A host that owns its own markup — a rich-text editor, a block editor — enhances an existing <table> with no wrapper element, so its saved HTML stays clean. Inside a contenteditable ancestor the component adds UI only: the host keeps ownership of editability and keyboard handling.
