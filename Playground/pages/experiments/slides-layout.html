Slide Layout

A placement map for nui-slides: blocks are positioned on the slide surface, while the document stays ordinary Markdown.

How it is authored

A section carries an mb:var name=layout whose JSON payload maps a block id to a rectangle in percentages of the slide surface, origin top-left:

The rules. Every visible block needs an id and an area — the map is all-or-nothing for its section, and an incomplete one falls back to flow with a console message. Document order is the default paint order; an area may carry z when reading order and paint order disagree, valign (start|center|end) and align (start|center|end) for alignment inside the rectangle, fit (cover|contain) for media blocks, and mode (light|dark) for block-level colour scheme overrides.

Invisible in generic Markdown previews when inline. Authoring the map as <!-- mb:var name=layout value={...} --> keeps it inside the HTML comment, so GitHub, VS Code and Obsidian previews show zero JSON code blocks.

The frame stays on top. Header, footer and slide counter paint above placed areas (z 10), so a full-bleed plate passes behind the header rather than hiding it; <!-- mb:var name=chrome value=none --> suppresses chrome on title or full-bleed slides.
