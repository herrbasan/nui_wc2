Slide Patterns

Seventeen presentation compositions across three layout layers — keeping 95% of slides pure, map-free Markdown.

The Three-Layer Model

PatternLayerHow it is built
Title / ClosingLayer 1 (Flow)mb:section preset=center (or center:middle) + mb:var name=chrome value=none
Section dividerLayer 1 (Columns)mb:section preset=center + mb:columns weights=[1,3]
Plain flow / Code / TableLayer 1 (Flow)Ordinary Markdown and block presets in source order
Text 60 / Image 40 (& mirror)Layer 1 (Columns)mb:columns weights=[3,2] and weights=[2,3] — zero JSON, zero IDs
Agenda / RailLayer 1 (Columns)mb:columns weights=[2,3] / [1,3] with mb:col preset=top on the left rail
QuoteLayer 1 (Flow)mb:section preset=center + preset=card:quote
Light slide in dark deckLayer 1 (Flow)mb:var name=mode value=light + preset=center
Full-bleed plate + captionLayer 2 (Overlay)preset=image:hero:bleed + preset=card:scrim:bottom-left — zero JSON
AI Atom diagram + overlayLayer 2 (Overlay)preset=image:hero + preset=card:scrim:bottom + mode value=light — zero JSON
Multi-box poster over imageLayer 3 (Map)mb:var name=layout with z, fit: "cover", valign, and block-level mode
Stats / Features / GalleryLayer 1 (Flow/Cols)mb:columns and preset=gallery:row

Why three layers instead of putting everything in a JSON map. Fenced ```json blocks are visible in GitHub, VS Code and Obsidian Markdown previews, and splitting a heading and its prose into separate y/h percentage boxes causes text collisions whenever a heading wraps. Layer 1 (flow, columns, vertical alignment) and Layer 2 (image:hero:bleed + card:scrim:<slot>) express 16 of these 17 slides using only invisible HTML comments, reserving Layer 3 (mb:var name=layout) for genuinely freeform multi-box compositions.
