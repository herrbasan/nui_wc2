Blocks Editor

Visual editor for MD-Blocks documents — <nui-blocks-editor> addon.

What this page wires

The addon ships no media of its own. Everything a host supplies is wired in Playground/js/page-init.js, which makes this page the integration example rather than just a demo.

Without these the media picker opens to a named empty state (“No media library is wired”) rather than a silent empty list — an unfinished integration should look like one. resolveThumb is additive: a single-argument resolver keeps working and serves both sizes identically. Returning null falls back to the stored src.
