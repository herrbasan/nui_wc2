Form Row

A layout element for placing form controls side by side at a matching height.

Why the row owns the height

nui-button has no size vocabulary — 2rem is its base height — while nui-input and nui-select default to 2.5rem. Two controls with different vocabularies cannot be matched from the control side, so the row reconciles them: it owns the height every child resolves against.

Compact rows

size="small" drops the whole row to 2rem. Declare it on the row, never per control — a per-control size="small" can never line a row up on its own, because the button's height is not a size you can set.

The row wraps when its controls do not fit, and it does not bind a label to a control. Use nui-input-group when a control needs its own label, description and validation state — the two elements are independent and can be nested.
