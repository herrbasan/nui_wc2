File Icon

A document glyph with the extension overlaid and coloured by category. In small size, collapses to just the colored extension badge.

By Extension

Pass type or extension (with or without the dot) when the file extension is known directly.

Try It

By Filename / Path

Given name, the extension is automatically derived. Path directories are skipped, and dotfiles without extension render as neutral file types.

Try It

Sizes

nui-file-icon supports three sizes: default, large, and small.

  • Default: Standard document sheet (~2rem × 2.5rem) with folded corner flap, document lines, and colored extension label.
  • Large (size="large"): Expanded sheet (~3rem × 3.75rem) for detail cards and previews.
  • Small (size="small"): Strips the document outline entirely, rendering only the colored extension text. Designed for dense tree views, table rows, and inline lists.

Attributes

AttributeTypeDescription
namestringFilename or path. The extension is derived from the last dot of the last segment.
type / extensionstringExplicit extension, with or without leading dot. Takes precedence over name.
sizestring"small" (badge only), "large" (detail view), or omit for default glyph.
labelstringSets role="img" and aria-label for standalone use when no adjacent filename exists.

Extension & Color Mapping
