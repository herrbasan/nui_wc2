Date Range

A from/to date pair with optional presets, built on the browser's native date picker.

Overview

The <nui-date-range> component owns the reconciliation between a preset list and two hand-editable date fields, so a caller only handles one normalized { from, to, preset } event.

It comes in two presentations: the default inline pair, which leans on the browser's native picker and stays keyboard- and locale-correct for free, and a calendar mode that swaps in a month grid. Both share one value store, so the behaviour below is identical in each.

Calendar Mode

Add calendar and the two date inputs collapse into a single button showing the resolved range. Opening it gives a month grid — click a start then an end, or drag across the days. The preset <select> still drives the chips in the sidebar; it is never removed from the value model.

Nothing is committed until Apply

Picking days, dragging, typing in the manual fields and clicking a chip all edit a draft. The committed range is untouched while the panel is open, and no event fires — which is exactly what makes Cancel possible, and means getValue() returns the committed range, not whatever you are trying out.

Closing by Apply commits and emits; closing by Cancel, Escape or a click outside discards. The preset selection travels with the draft, so a chip's identity survives into detail.preset, and picking days by hand clears it again.

With Presets

A <select> child becomes the preset list. Ranges are inclusive on both ends, so 7d is today plus the six days before it.

Try It

Event detail: pick a preset or type a date

The preset <nui-select> is a child, not a sibling. The component only looks for a <select> among its own children — a preset list placed next to it renders correctly and silently does nothing.

Note also the event name: nui-date-range-change, not nui-change. A child <nui-select> fires its own nui-change (carrying { values, labels, options }) straight through this element, so one shared listener would receive both payloads.

Bare Pair

The preset select is optional. The two marked inputs are the required part.

Inverted Ranges Are Clamped

Typing a from later than the current to pushes to up to match. The field you are typing in wins, so your intent survives. A reversed range would match nothing and otherwise look like a data outage.

Component API

Methods

Method Description
getValue() Returns { from, to }, both YYYY-MM-DD strings or '' when unbounded.
setValue({ from, to, preset })Sets the range and emits nui-date-range-change. Passing preset resolves it against the current clock instead.
clear()Empties both fields.
getPreset() / setPreset(v)Read or drive the preset select. Only present when a <select> child exists.
setDensity(map, opts)Calendar mode only. Marks days by volume from { 'YYYY-MM-DD': n }; opts.max overrides the normalisation ceiling. Drawn as a bar under the number, not a cell fill, so it can never be read as a selected range.
openCalendar()Calendar mode only. Opens the panel programmatically.

Events

Event Description
nui-date-range-change Bubbles with { from, to, preset }. preset is '' for hand-entered or programmatic ranges. Not named nui-change: a child preset select's own nui-change bubbles through this element carrying a different payload.
