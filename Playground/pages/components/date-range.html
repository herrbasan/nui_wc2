Date Range

A from/to date pair with optional presets, built on the browser's native date picker.

Overview

The <nui-date-range> component owns the reconciliation between a preset list and two hand-editable date fields, so a caller only handles one normalized { from, to, preset } event.

It deliberately adds no calendar popup — the native picker is used as-is, which keeps it keyboard- and locale-correct for free.

With Presets

A <select> child becomes the preset list. Ranges are inclusive on both ends, so 7d is today plus the six days before it.

Event detail: pick a preset or type a date

The preset <nui-select> is a child, not a sibling. The component only looks for a <select> among its own children — a preset list placed next to it renders correctly and silently does nothing.

Note also the event name: nui-date-range-change, not nui-change. A child <nui-select> fires its own nui-change (carrying { values, labels, options }) straight through this element, so one shared listener would receive both payloads.

Bare Pair

The preset select is optional. The two marked inputs are the required part.

Try It

Inverted Ranges Are Clamped

Typing a from later than the current to pushes to up to match. The field you are typing in wins, so your intent survives. A reversed range would match nothing and otherwise look like a data outage.

Component API

Methods

Method Description
getValue() Returns { from, to }, both YYYY-MM-DD strings or '' when unbounded.
setValue({ from, to, preset }) Sets the range and emits nui-change. Passing preset resolves it against the current clock instead.
clear() Empties both fields.
getPreset() / setPreset(v) Read or drive the preset select. Only present when a <select> child exists.

Events

Event Description
nui-date-range-change Bubbles with { from, to, preset }. preset is '' for hand-entered or programmatic ranges. Not named nui-change: a child preset select's own nui-change bubbles through this element carrying a different payload.
