Virtual Scroll (Variable Height)

Detached-element recycler for arbitrary variable-height DOM items — preserves component state, cascades live height changes at 60fps, and anchors scroll position when off-screen items resize or delete.

Interactive Recycler Demo

Unlike uniform-row virtual lists, <nui-virtual-scroll> (and nui.util.virtualScroll) measures arbitrary variable-height elements once in natural flow, stages them with an explicit pixel height, and detaches off-screen nodes via removeChild so only the visible viewport window stays in the browser's layout tree.
