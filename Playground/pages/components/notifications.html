Notifications

A store-backed notification log — banners become a transient echo, the log keeps the record

How it works

Notifications are data first: nui.notify() (or nui.components.banner.show()) appends to a single in-memory store, and three views react to it — the badge on the header bell (top right of this Playground), the <nui-notification-log> panel that opens from that bell, and optionally a transient banner. Every banner shown anywhere in the app is logged automatically, so a message that flashed by is always recoverable from the log.

Banner integration

nui.components.banner.show() logs to the same store by default — every banner on the Banner page ends up in the log. Pass log: false for pure UI feedback that carries no information (progress hints, drag state), and pass an id when the same notification may be shown repeatedly.

Embedded log

The log is a plain component, not married to the popover — embedded directly in a page it simply renders the store, live.
