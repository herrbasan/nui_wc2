Details Component

A styled <details> wrapper with built-in lazy loading support.

Static Content (Default)

Without a src attribute, <nui-details> acts as a styled wrapper for any HTML content. Children render immediately.

This component is part of the NUI library. It's free to use in any project.

The styling adapts to light and dark themes automatically.

Immediate Load from URL

With a src attribute pointing to a .md or .html file, content is fetched and rendered immediately on page load.

Lazy Load

Add the lazy attribute to defer loading until the user opens the details. The content is cached after the first fetch, so subsequent opens are instant.

Content Type Detection

Content type is auto-detected from the file extension:

ExtensionRender MethodUse Case
.mdRenders via <nui-markdown>Documentation, guides
.htmlInjected as innerHTMLHTML fragments, templates
Other / noneInserted as plain textCode, logs
