Storage

The nui.util.storage object provides a simple getter/setter API for storing text values with TTL (time-to-live) support. It's designed for simple use cases like theme preferences, session tokens, or user settings.

Basic Usage

Storage Targets

Target Persistence Size Limit Sent to Server
cookie Configurable (TTL) ~4KB per cookie Yes (every request)
localStorage Configurable (TTL) ~5-10MB total No

TTL (Time-to-Live)

Format Example Description
forever'forever'Never expires (10 years)
session'session'Expires when browser closes
N-minutes'30-minutes'Expires in N minutes
N-hours'2-hours'Expires in N hours
N-days'7-days'Expires in N days
YYYY-MM-DD'2025-12-31'Expires end of that date

registerType

Register a handler for #<type>=<id> routes. Note the different argument order — the route id comes first and the wrapper last:

⚠️ registerFeature and registerType both take three arguments in a different order. Swapping them raises no error: wrapper is then truthy but wrong, so wrapper.innerHTML = '…' silently writes somewhere unexpected instead of throwing. A custom type also gets no theme styling — see architecture-patterns.md.
