Smooth Streaming (Opt-In)

The smooth attribute pans the chart continuously between sample updates (like the opnSense dashboard): the line glides leftward at the sample rate and a "head dot" rides the right edge until the next value lands.

Performance: the animation loop runs only while the stream is fresh (within 1.5× the sample interval after the last push()). Paused streams, idle graphs and static data attributes revert to the default paint-on-change path with zero rAF loops. Below, both graphs get identical data — toggle the stream to compare.
