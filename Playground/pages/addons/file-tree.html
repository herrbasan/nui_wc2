File Tree

A lazy-loading file explorer tree. The component is filesystem-agnostic — the host provides directory data, the tree handles expansion, selection, and keyboard navigation.

Static Tree (loadData)

For static or already-known structures, pass a nested data object — no provider needed. Dirs start collapsed and expand on click.

Async Provider (Lazy Loading)

The real use case for large trees: hand the tree a readdir(path) provider and a root. Children are fetched lazily on first expansion. This demo simulates an async remote filesystem API with simulated latency, so it works reliably on any static web hosting.

Component API

MemberTypeDescription
setProvider(fn)methodSet the directory provider: (path) => Promise<entries>. Required for dynamic trees.
setRoot({ name, path })method (async)Open a dynamic root via the provider.
loadData(rootNode)methodRender a static nested tree. No provider needed.
refresh(path?)method (async)Re-fetch the tree (or one directory), preserving expansion state.
expand(path) / collapse(path) / toggle(path)methodsProgrammatic expansion control.
collapseAll()methodCollapse all currently open directories.
expandAll(maxDepth?)method (async)Expand all directories up to maxDepth (default: 3).
select(path)methodProgrammatic selection. Path must be loaded.
getSelected()methodReturns the selected entry { name, path, kind } or null.
filterpropertystring substring search, fn(entry) predicate, or array of extensions (['.md']). null shows all.
sortpropertyCustom comparator. Default: dirs first, then natural alpha.
selectableattributeall (default) | files | dirs.
densityattribute / propcozy (default, ~30px rows with comfortable spacing) | compact (24px high density).
open-modeattribute / propsingleClick (default) | doubleClick. In double-click mode, single click selects (preview), double-click activates/toggles. Caret twistie always toggles on single click.
