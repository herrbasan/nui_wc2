File List

Files with type icons, names, optional status and per-row actions — the shape an upload dropzone stages into, and the shape a document library displays.

Basic Usage

Give it files and it renders rows. The download action is only rendered when a file has a url, so no control is ever dead.

Try It

Upload Staging List

A status renders as a badge. Useful while files are still being transferred — the list is the same component either way.

Try It

Sortable

Set sortable: true to reorder by drag. nui-sortable is a core component, so this adds no second import. Reordering is reported, not performed on your data: the host owns the array, so the list reorders its own copy and dispatches nui-file-reorder — cancel that event and the rows snap back.

Events

Interact with a list to see events here.

EventDetailFires
nui-file-action{ action, file, index }Any row action — the catch-all handler.
nui-file-remove{ action, file, index }Remove requested. preventDefault() keeps the file in the list.
nui-file-download{ action, file, index }Download requested. preventDefault() suppresses the built-in download.
nui-file-removed{ file, index }After the file has been removed.
nui-file-reorder{ files, order }After a drag. preventDefault() refuses the new order.

Methods

MethodDescription
loadData(files, options)Replace the list. Throws TypeError if files is not an array.
addFiles(files)Append without a full reload.
removeFile(fileOrIndex)Remove one entry; returns false when it is not present.
getFiles()A copy of the current list.
clear()Empty the list.

Options: actions (keys of download, remove, preview, open — or your own key, dispatched as nui-file-<key>), sortable, emptyText, onAction(action, file, index). A file is { name, size, url, detail, status, id }; size may be a byte count or a string.
