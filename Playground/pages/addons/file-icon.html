File Icon

One document glyph, the extension overlaid, the colour picked by category — so a mixed file list reads as one system instead of as a pile of unrelated icons.

By Extension

Pass type (with or without the dot) when only the type is known.

Try It

By Filename

Given name, the extension is derived — a path's directories are skipped, and a dotfile has no extension.

Try It

Sizes and Standalone Labels

Without a label the glyph is decorative — right beside a filename. With one it becomes a labelled img, so a bare icon still says what it is.

Try It

An unknown extension is not an error: it renders the neutral file state. A malformed type (anything outside [a-z0-9+]) throws, because that is a typo rather than a type.

Attributes

AttributeTypeDescription
namestringFilename or path. The extension is derived from the last dot of the last segment.
type / extensionstringAn explicit extension, with or without a leading dot. Takes precedence over name.
sizestring"small" for dense rows, "large" for a detail view. Omit for the default.
labelstringMakes the icon a labelled role="img" for standalone use. Omit it when a filename is adjacent.
