Slides

Presentation profile for MD-Blocks documents, rendering each section as a scaled canvas surface.

Live Presentation Deck

The slide deck below is placed directly in the normal page flow. It includes an integrated toolbar for non-fullscreen navigation, swipe gesture support on touchscreens, and auto-scales cleanly to any width.

Narration blocks (preset=narration) are delivery text: the deck hides them on the slide, and the notes attribute surfaces the current slide's narration underneath it — with a play control that reads it through the same speech hook the block controls use. Without notes the words stay in the DOM for a delivery profile and are never drawn. The same text is in nui-slide-change as detail.narration.

Declarative Usage

Wrap any <nui-markdown> element in a <nui-slides> container. Sections delimited by --- become individual slides. Add the optional toolbar attribute to render a floating navigation bar in non-fullscreen mode.

Repeating Chrome & MD-Blocks

Chrome blocks (headers and footers) are defined once on the document's main scope using repeat=header or repeat=footer. nui-slides automatically clones them onto each slide in that scope, while keeping slide numbers dynamically computed.

Keyboard Controls

When focus is within the deck, the following keyboard navigation keys are active:

Key Action
ArrowRight, ArrowDown, PageDown, Space Advance to next slide
ArrowLeft, ArrowUp, PageUp Return to previous slide
Home / End Jump to first / last slide
g / G Toggle slide overview grid (or click the 1 / N counter in the toolbar)
f / F Toggle fullscreen presentation mode

Three-Layer Slide Layout & Custom Patterns

Decks stay clean Markdown by using three progressive layout layers — see the live 18-Slide Pattern Catalogue, Layer 3 Layout Map, and AI Atom Deck:

  • Layer 1 (Flow & Columns — ~85% of slides, 0 JSON): mb:columns weights=[3,2], mb:section preset=center (or center:middle), mb:col preset=top|bottom, and per-slide vars (chrome, mode, dwell, font-size, font-scale).
  • Layer 2 (Bleed Plates & Scrim Overlays — ~12% of slides, 0 JSON): preset=image:hero:bleed + preset=card:scrim:bottom (or bottom-left, bottom-right, top, top-left, top-right, center).
  • Layer 3 (Coordinate Map — ~3% of slides): mb:var name=layout mapping block id → { x, y, w, h, z, valign, align, fit, mode }.

Component API

Attributes

Attribute Type Default Description
base string "1280x720" Logical canvas size ("1280x720", "1024x768", or width "1600"). In page flow, the component automatically sets its aspect ratio to match.
toolbar boolean _none_ When present, provides a control bar under the slide (navigation, autoplay/narration, fullscreen, settings). Floats at the bottom in fullscreen.
notes boolean _none_ Surfaces the current slide's preset=narration blocks as speaker notes below the toolbar with a play/stop control.
narrate boolean _none_ Automatically speaks each slide's narration during autoplay and waits for speech to finish before advancing.
dwell / narration-delay number 5 / 1 Silent slide duration (s) and post-narration pause (s) during autoplay.
font-size / font-scale string / number "1.2rem" / 1 Base slide font size and boost multiplier (0.5–2.5, also adjustable live via the settings dialog's Font size boost slider or YAML frontmatter).
mode string "auto" Forces deck colour scheme ("auto", "light", or "dark").
height string _none_ Set to "fill" to fill 100% of an explicit parent container height, or "viewport" for standalone 100dvh kiosk display. Omit for natural page flow (responsive 16:9).

Methods & Properties

Member Type Description
show(index) Method Navigates to the slide at the specified 0-based index.
next() Method Advances to the next slide.
prev() Method Returns to the previous slide.
current Property (get) Current active 0-based slide index.
count Property (get) Total number of slides in the deck.
nui.components.slides.show(i, el?) Factory Programmatically show slide i on a deck.
nui.components.slides.next(el?) Factory Programmatically advance to next slide.
nui.components.slides.prev(el?) Factory Programmatically go to previous slide.

Events

Event Detail Description
nui-slide-change { index, count, section } Fires whenever the active slide changes.
nui-slides-error { message } Fires if the presentation deck fails to mount or parse markdown content.
